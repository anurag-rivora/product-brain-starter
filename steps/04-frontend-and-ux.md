# Step 4: Frontend and UX

**Reads:** Step 2 and Step 3 (approved).

## Think through

- [ ] Which screens are affected?
- [ ] The flow, step by step.
- [ ] Every state: empty, loading, error, success, no permission.
- [ ] Validation rules, with the exact message for each.
- [ ] Permissions: who sees and does what.
- [ ] Accessibility.
- [ ] Mobile behaviour.
- [ ] Copy: labels, buttons, messages.
- [ ] Analytics events: trigger and properties. Properties never carry personal details.

## Watch for

- Reuse existing patterns and components before inventing new ones.
