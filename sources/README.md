# Sources

Put transcripts, meeting notes, call summaries and exported documents here. Name them with the date first, for example `2026-11-12-billing-sync.md`.

Rules:

- The AI never loads this folder whole. It is too big and buries the rules that matter.
- Entries in `brain/` cite a file here. The AI opens a source only to check a claim.
- Do not put anything here you would not want an AI tool to read. Remove personal details and anything confidential first.
- Never edit a source after the fact. Add a new file if something changes.
